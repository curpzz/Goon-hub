# GOON HUB
A lightweight, responsive gaming site with three built-in games.

## Deploy on Render
1. Create a GitHub repository named `goon-hub`.
2. Upload the contents of this folder to the repository root (not the ZIP file itself).
3. In Render, choose **New → Blueprint** and connect the repository.
4. Render reads `render.yaml` and creates the static site.

No build command is required.
